# Common AI-Driven Development Methodologies

| Methodology | Description |
|------------|-------------|
| AI-Augmented Development | Developers use AI assistants (GitHub Copilot, Claude, ChatGPT, Gemini, etc.) throughout the SDLC. |
| AI-Driven Software Development (AISD) | AI assists in requirements gathering, design, coding, testing, deployment, and maintenance. |
| Agentic Development | Autonomous AI agents collaborate to design, code, test, review, and optimize software. |
| AI-Native Development | Applications are designed around AI capabilities from inception rather than adding AI later. |
| LLMOps | DevOps practices applied to LLM-based applications, including deployment, monitoring, governance, and lifecycle management. |
| AIOps | AI-driven operations, monitoring, incident management, observability, and reliability engineering. |
| DevSecOps with AI | Security is integrated into AI-assisted development pipelines through automated risk detection and compliance validation. |
| Intelligent Automation SDLC | AI-powered automation is leveraged across the entire software development lifecycle. |
| Human-in-the-Loop (HITL) Development | AI generates outputs while humans govern, review, validate, and approve critical decisions. |
| Prompt-Driven Development (PDD) | Requirements, designs, tests, and code generation are primarily driven through structured prompts. |
| Model-Driven Development (MDD) + AI | Software artifacts are generated from models using AI assistance for acceleration and optimization. |
| Test-Driven Development (TDD) with AI | AI generates, maintains, and optimizes test cases before or alongside implementation. |

## Industry Buzzwords Often Seen Together
