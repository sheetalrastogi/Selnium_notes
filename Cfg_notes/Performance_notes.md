For Performance Testing Scope, you typically want to evaluate not just speed, but also scalability, stability, capacity, resource utilization, recovery, and user experience.

### PERFORMANCE

#### Time-Based Metrics
- RESPONSE TIME
- PAGE LOAD TIME
- API RESPONSE TIME
- TRANSACTION COMPLETION TIME
- DATABASE QUERY EXECUTION TIME
- START-UP TIME
- SHUTDOWN TIME
- RECOVERY TIME
- FAILOVER TIME
- CACHE WARM-UP TIME

#### Throughput & Capacity
- THROUGHPUT (TPS/RPS)
- CONCURRENT USERS SUPPORTED
- CONCURRENT SESSIONS
- TRANSACTIONS PER SECOND (TPS)
- REQUESTS PER SECOND (RPS)
- BATCH PROCESSING RATE
- MESSAGE PROCESSING RATE

#### Resource Utilization
- CPU UTILIZATION
- MEMORY UTILIZATION
- DISK USAGE
- DISK I/O
- NETWORK BANDWIDTH UTILIZATION
- DATABASE CONNECTION POOL UTILIZATION
- THREAD UTILIZATION

#### Scalability
- HORIZONTAL SCALABILITY
- VERTICAL SCALABILITY
- AUTO-SCALING EFFICIENCY
- ELASTICITY UNDER LOAD
- PEAK LOAD HANDLING

#### Stability & Reliability
- ENDURANCE / SOAK PERFORMANCE
- MEMORY LEAK DETECTION
- RESOURCE LEAK DETECTION
- LONG-RUN STABILITY
- ERROR RATE UNDER LOAD
- SYSTEM AVAILABILITY

#### Resilience & Recovery
- APPLICATION RECOVERY TIME
- DATABASE RECOVERY TIME
- FAILOVER PERFORMANCE
- FAILBACK PERFORMANCE
- DISASTER RECOVERY PERFORMANCE
- SERVICE DEGRADATION BEHAVIOR
- GRACEFUL SHUTDOWN PERFORMANCE

#### Data & Database Performance
- QUERY PERFORMANCE
- INDEX PERFORMANCE
- BULK DATA LOAD PERFORMANCE
- BULK DATA EXPORT PERFORMANCE
- DATABASE LOCKING/CONTENTION
- REPLICATION LAG
- DATA SYNCHRONIZATION PERFORMANCE

#### User Experience
- FIRST CONTENTFUL PAINT (FCP)
- LARGEST CONTENTFUL PAINT (LCP)
- TIME TO INTERACTIVE (TTI)
- SCREEN RENDERING TIME
- UI RESPONSIVENESS
- SEARCH PERFORMANCE
- REPORT GENERATION TIME

#### Background Processing
- JOB EXECUTION TIME
- SCHEDULER PERFORMANCE
- QUEUE PROCESSING TIME
- EVENT PROCESSING LATENCY
- NOTIFICATION DELIVERY TIME

#### Cloud & Microservices
- SERVICE LATENCY
- INTER-SERVICE COMMUNICATION LATENCY
- API GATEWAY PERFORMANCE
- CONTAINER START-UP TIME
- POD SCALING TIME
- MESSAGE QUEUE LATENCY
- CACHE HIT/MISS PERFORMANCE
