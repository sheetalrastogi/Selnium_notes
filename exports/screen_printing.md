For screen printing screen (stencil) preparation, the chemicals depend on whether you are making a photo-emulsion screen, which is the most common commercial method.

```text
1. Screen Degreaser

Used to clean mesh before coating.

Examples:

Mesh Prep
Screen Degreaser Concentrate
Detergent-based degreasing solution
2. Photo Emulsion

Light-sensitive chemical coated onto the mesh.

Types:

Diazo Emulsion
SBQ (Pure Photopolymer) Emulsion
Dual-Cure Emulsion

Popular brands:

Ulano
Murakami
KIWO
Chromaline
3. Diazo Sensitizer

Mixed with diazo or dual-cure emulsions before use.

4. Emulsion Remover (Stencil Remover)

Used to reclaim screens after printing.

Chemicals:

Sodium Periodate-based remover
Potassium Periodate-based remover
5. Haze Remover / Ghost Image Remover

Removes residual ink stains after reclaiming.

Chemicals:

Sodium Hydroxide formulations
Oxalic Acid formulations
Specialized haze remover paste
6. Ink Degrader / Screen Wash

Used to remove ink from screens.

Depending on ink type:

Solvent Screen Wash
Plastisol Ink Remover
Water-Based Ink Cleaner
UV Ink Cleaner
7. Emulsion Hardener (Optional)

Improves stencil durability for long print runs.

Chemicals:

Diazo Hardener
Cross-linking hardeners
8. Adhesive for Pallets

Used to hold fabric/paper during printing.

Types:

Water-based pallet adhesive
Spray adhesive
Typical Chemical Kit for Starting a Screen Printing Unit
Screen Degreaser
Photo Emulsion
Diazo Sensitizer
Screen Wash / Ink Remover
Emulsion Remover
Haze Remover
Pallet Adhesive
Textile/Paper/UV Printing Inks
Basic Raw Chemicals Used in Manufacturing Screen Printing Emulsion
Polyvinyl Alcohol (PVA)
Acrylic Polymers
Diazo Compounds
SBQ Photoinitiators
Distilled Water
Surfactants
Preservatives

These are the main chemicals if you are planning to manufacture screen printing emulsions, whereas for screen preparation and printing, the first list is sufficient.
```
