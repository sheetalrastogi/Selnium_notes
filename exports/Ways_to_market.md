### 1. Google extensions

| Extension | Best For | Export Format |
|-----------|----------|---------------|
| Maps Scraper AI | Extract businesses from Google Maps searches | CSV, Excel |
| G | Bulk extraction of company details | CSV |
| Instant Data Scraper | General web scraping including Maps results pages | CSV, XLSX |
| Outscraper Chrome Extension | Google Maps lead generation | CSV, API |
| Scrape | Business directory extraction | CSV |
| Data Miner | Custom extraction recipes | CSV, Excel |
| SimpleScr | No-code scraping workflows | CSV, Google Sheets |
| Apify Google | Large-scale Maps data collection | CSV, JSON |
| ExtensionsBox | Maps-specific lead collection | CSV |
| Maps Leads Scraper | Local business prospecting | CSV |
