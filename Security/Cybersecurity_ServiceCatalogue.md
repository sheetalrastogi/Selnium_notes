This slide presents a SOC Service Catalogue, which defines the cybersecurity services offered by a Security Operations Center (SOC) team to its customers. Think of it as a menu of security services an organization can consume.

The services are grouped into three major categories:

1. Security Operations Center (SOC)
Setup, Execution & Governance

This is the core operational SOC service responsible for monitoring, detection, response, and governance.

Services Offered
A. Security Incident Monitoring & Handling

Purpose Continuously monitor security events and respond to incidents.

Activities

24×7 Security Monitoring
Alert Triage
Incident Investigation
Incident Escalation
Incident Reporting

Examples

Malware detection
Unauthorized access attempts
Ransomware alerts
Suspicious network traffic
B. Emergency Response Planning

Purpose Prepare and respond to major cyber incidents.

Activities

Incident Response Playbooks
Crisis Management
Breach Response
Disaster Recovery Coordination

Example

Ransomware Attack
       ↓
Containment
       ↓
Investigation
       ↓
Recovery
       ↓
Lessons Learned

2. Threat & Vulnerability Management

This service identifies cybersecurity weaknesses and threats before they become incidents.

A. Threat Detection (PT)

PT = Penetration Testing

Purpose

Simulate real-world attacks to identify exploitable weaknesses.

Activities
External penetration testing
Internal penetration testing
Web application testing
Network testing
Cloud testing
Example
Find Open Port
      ↓
Attempt Exploitation
      ↓
Document Vulnerability
      ↓
Provide Fix Recommendation

Deliverable

Penetration Test Report containing:

Vulnerabilities
Risk Ratings
Proof of Concept
Remediation Plans
B. Vulnerability Detection (VA)

VA = Vulnerability Assessment

Purpose

Identify known vulnerabilities using automated tools.

Activities
Server scanning
Database scanning
Application scanning
Configuration assessment
Common Tools
Tenable Nessus
Qualys
Rapid7
OpenVAS
Difference Between VA and PT
Vulnerability Assessment (VA)	Penetration Testing (PT)Finds vulnerabilities	Exploits vulnerabilities
Mostly automated	Largely manual
Broad coverage	Deep analysis
Continuous assessment	Periodic testing

Simple Summary

This service catalogue offers three pillars of cybersecurity services:

1. SOC Operations
Monitor security events
Handle incidents
Manage SIEM tools
Onboard assets
2. Threat & Vulnerability Management
Penetration Testing (PT)

Technology Consulting

Together, these services cover the full cybersecurity lifecycle: Assess → Protect → Monitor → Detect → Respond → Recover → Improve.
