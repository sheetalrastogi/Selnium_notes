2. Threat & Vulnerability Management

This pillar focuses on finding, testing, and fixing security weaknesses.

Activities

Web Application Testing
API Security Testing
Cloud Security Testing
Social Engineering Testing

Executive Summary

The service catalogue offers a complete cybersecurity program built around three capabilities:

SOC Services

Monitor, detect, respond, and govern security operations.

Threat & Vulnerability Management

Assess vulnerabilities, perform penetration testing, and remediate risks.

Security Control & Technology Management

Provide security consulting, architecture guidance, governance, and technology optimization.

In simple terms:

Protect  →  Assess  →  Detect  →  Respond  →  Remediate  →  Improve


This covers the full cybersecurity lifecycle from security assessment and vulnerability management to continuous SOC monitoring and incident response.
