1. Assessment Checkpoints

The first slide refers to a detailed questionnaire used during cybersecurity assessments.

Purpose

The checkpoint questionnaire helps determine:

✅ Current security maturity

✅ Compliance status

✅ Technology gaps

✅ Process gaps

✅ Governance effectiveness

✅ Readiness for certifications

Sample Assessment Areas
Governance

Questions like:

Is there an Information Security Policy?
Is there a Risk Management Program?
Is there a Security Steering Committee?
Are security responsibilities defined?
Asset Management
Are all assets inventoried?
Is there a CMDB?
Are asset owners assigned?
Identity & Access Management
Is MFA implemented?
Are privileged accounts monitored?
Are user access reviews performed?
Incident Management
Is there an Incident Response Plan?
Are incidents documented?
Are lessons learned recorded?
Vulnerability Management
Are VAPT assessments conducted regularly?
Are findings remediated?
Are rescans performed?
Compliance Management
Is ISO 27001 adopted?
Is PCI-DSS applicable?
Are audits performed regularly?
Expected Deliverables

At the end of the assessment:

Deliverable	DescriptionGap Assessment Report	Current vs desired state
Maturity Assessment	Security maturity score
Compliance Assessment	Standards compliance status
Risk Register	Risks identified
Improvement Recommendations	Remediation roadmap
2. Recommended Assessment Frameworks

The second slide shows the major frameworks and standards used during security assessments.

NIST Cybersecurity Framework (NIST CSF)
Purpose

Provides a cybersecurity risk-management framework.

Core Functions:

Identify
Protect
Detect
Respond
Recover

Used For
Security maturity assessments
Gap analysis
Security roadmaps
CIS Controls
Purpose

Provides practical security controls.

Examples:

Asset Management
Vulnerability Management
Secure Configurations
Logging & Monitoring
Why Popular

Provides actionable security controls.

ISO 27001
Purpose

Information Security Management System (ISMS).

Focus Areas:

Risk Management
Security Policies
Governance
Compliance
Outcome

Organizations can become ISO 27001 certified.

OWASP
Purpose

Application Security Framework.

Used for:

Web Applications
APIs
Mobile Applications

Focus:

OWASP Top 10 Risks
Secure Development
NERC CIP
Purpose

Critical Infrastructure Protection.

Primarily used by:

Energy
Utilities
Power Grid Operators
SOC (AICPA SOC Reports)
Purpose

Service Organization Controls (SOC 1, SOC 2).

Commonly required by:

SaaS providers
Cloud providers
Managed service providers

SOC 2 focuses on:

Security
Availability
Confidentiality
Privacy
HIPAA
Purpose

Healthcare security and privacy standard.

Protects:

Patient Health Information (PHI)

Used by:

Hospitals
Healthcare providers
Health-tech companies
PCI-DSS
Purpose

Payment Card Industry Data Security Standard.

Applies when handling:

Credit cards
Debit cards
Payment transactions

Requirements include:

Encryption
Access Control
Logging
Vulnerability Management

Interview Summary

If asked "What checkpoints should be covered during a cybersecurity assessment?", a strong answer is:

Governance & Policies
Asset Management
Risk Management
IAM & Access Control
Vulnerability Management
Incident Response
Monitoring & Logging
Business Continuity & DR
Regulatory Compliance
Technology Effectiveness

The referenced frameworks (NIST, CIS, ISO 27001, OWASP, HIPAA, PCI-DSS, SOC 2) provide the assessment criteria, while vendors like Microsoft, IBM, CrowdStrike, Cisco, McAfee, Forcepoint, and Micro Focus provide the technologies used to implement and monitor those controls.
