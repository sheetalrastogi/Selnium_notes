how to identify recently registered domain names from ICANN registry

If you're looking for recently registered domain names, ICANN does not provide a simple searchable list of newly registered domains. Instead, the common approach is to use Zone Files from ICANN's Centralized Zone Data Service (CZDS) and compare today's zone file with yesterday's to identify new registrations.

Method 1: Use ICANN CZDS (Official Source)
Step 1: Create a CZDS Account

Visit:

https://czds.icann.org

The Centralized Zone Data Service (CZDS) allows approved users to request access to gTLD zone files (.com, .shop, .online, .store, etc.).

Step 2: Request Zone File Access

After login:

CZDS
→ Available Zone Files
→ Request Access
→ Accept Terms


Registry operators approve or deny requests.

Step 3: Download Daily Zone Files

Zone files contain active domains for a TLD and are updated regularly. Approved users can download them periodically.

Step 4: Compare Daily Snapshots
Yesterday Zone File
today.com
abc.com

Today Zone File
today.com
abc.com
newdomain.com


Result:

newdomain.com


This identifies newly added domains.
