Everyone talks about ChatGPT, Claude and Gemini.

But there are so many other AI tools that are actually useful in day-to-day work.

Here are 15 AI tools worth knowing 👇

1. Perplexity → Research with sources you can actually check
2. NotebookLM → Upload PDFs, notes, videos or docs and ask questions about them
3. Cursor → AI coding agent that can understand and work across your codebase
4. v0 by Vercel → Describe a UI and generate working code
5. Lovable → Build a functional app from a plain-English prompt
6. Qodo → AI-powered code review and software quality checks
7. Postman Postbot → Generate API-related tests, documentation and other API work faster
8. Eraser → Turn natural-language descriptions into architecture diagrams, flowcharts and more
9. Napkin AI → Turn text into clean visuals for posts, documents and presentations
10. Gamma → Create presentations and other visual content from a prompt
11. Wispr Flow → Speak instead of typing and let AI clean up your words
12. Otter.ai → Record meetings and turn conversations into notes and action items
13. Julius AI → Upload spreadsheets or CSVs and ask questions about your data
14. n8n → Connect your apps and automate repetitive workflows
15. Descript → Edit videos and podcasts by editing the transcript

One rule I follow:

Let AI do the first draft.
The final decision stays with me.

Never ship something you don’t understand.

How many of these are you already using👇
